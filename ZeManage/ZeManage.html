Description

Ze'Manage is a BIM workflow management platform built for Autodesk Revit. It supports secure authentication, workflow governance, access management, and centralized BIM workflow monitoring across organizations and projects. Ze'Manage operates through a subscription-based access model with role-based access control for Company Admins, Project Admins, and Users.

The platform brings eight integrated toolkits directly into Revit to streamline daily BIM operations:

Protection Toolkit

Controls how elements, commands, and events are used within the model through Pin Protection, Command Protection, Event Restriction, and Rule Management — reducing accidental changes and improving project governance.

Activity Tracker Toolkit

Provides centralized session monitoring and user activity tracking through Session Information, Crash Register, and Model Activities — improving coordination and visibility into project workflows.

Health Monitor Toolkit

Brings hidden model conditions into view through Deep Analysis and Model Health — helping teams identify risks early and maintain cleaner, more efficient BIM data.

Sync Control Toolkit

Manages synchronization behavior through Sync Settings and Sync Queue — reducing sync conflicts and maintaining stable collaborative workflows across shared models.

Projects Toolkit

Centralizes project registration, secure authorization, and dashboard access through Register Model, Generate One Time Access Code, and Dashboard tools for streamlined administrative control.

Addons Toolkit

Automates repetitive BIM tasks through NWC Export (Navisworks coordination) and Link Remapper (reconnects missing links) — saving time and improving coordination preparation.

Ze AI Toolkit

Provides an integrated AI Assistant directly inside Revit, allowing users to ask BIM and workflow questions without leaving the modeling environment.

Support Toolkit

Centralizes account management, device registration, and support communication through Status, Account, and Support tools — keeping users connected and issues resolved quickly.

General Usage Instructions

Platform Overview

Ze'Manage operates on a structured access system with three roles: Company Admin (manages licensing, organization access, company settings and admin onboarding), Project Admin (manages projects and organises models within projects), and User (works within assigned projects directly through the Ze'Manage integration in Revit, no separate platform login required).

After installation and login, the dashboard becomes accessible inside Revit, modules are enabled based on role and license, and workflow tools are ready for use.

Toolkit Descriptions

Protection Toolkit

Includes four connected tools:

  • Pin Protection — keeps important BIM elements fixed so they do not move or get edited by mistake.
  • Command Protection — controls how selected Revit commands are used through Notify, Assist, or Protect modes.
  • Event Restriction — validates important project actions such as CAD Import or Sync with Central before completion.
  • Rule Management — applies consistent control settings across multiple elements and actions.

Activity Tracker Toolkit

Includes three connected tools:

  • Session Information — displays current Revit session details, environment information, and opened documents.
  • Crash Register — tracks session history and provides crash analysis through journal-based diagnostics.
  • Model Activities — shows active users connected to the project and monitors shared model participation.

Health Monitor Toolkit

Includes two connected tools:

  • Deep Analysis — performs a detailed scan to identify technical model issues such as duplicates, unused elements, and warnings.
  • Model Health — provides a visual dashboard to monitor overall model condition and cleanup opportunities.

Sync Control Toolkit

Includes two connected tools:

  • Sync Settings — defines and controls when and how model synchronization occurs through configurable rules for timing, user activity, and model maintenance.
  • Sync Queue — provides real-time visibility of synchronization activity, showing which users are syncing, waiting, or have completed sync operations.

Projects Toolkit

Includes three connected tools:

  • Register Model — confirms the model is ready for tracking.
  • Generate One Time Access Code — provides secure approval for protected actions such as removing locked elements or using restricted commands.
  • Dashboard — enables centralized project and user management directly inside Revit.

Addons Toolkit

Includes two connected tools:

  • NWC Export — converts Revit models for Navisworks coordination workflows.
  • Link Remapper — reconnects missing or broken Revit links quickly and efficiently.

Ze AI Toolkit

Includes one connected tool:

  • AI Assistant (Ze AI) — an integrated chat-based environment that allows users to ask BIM, Revit, and workflow questions directly inside Revit without leaving the modeling environment.

Support Toolkit

Includes three connected tools:

  • Status — displays system and registration details, license allocation, seat usage, and enabled modules.
  • Account — manages admin account information and access.
  • Support — enables direct communication with the Ze'Manage support team.

Getting Started

1. The organization shares its administrative structure (Company Admins, Project Admins, Users) and primary Company Admin email with ZestineTech.

2. ZestineTech configures the organization account and sends the onboarding invitation. The setup link is valid for 72 hours.

3. The primary Company Admin completes account setup, signs in to the Ze'Manage web portal, and invites additional Company Admins and Project Admins.

4. The Company Admin generates a license key from the Devices tab. License keys remain valid for 24 hours.

5. Users install Ze'Manage in Revit using the license key, select Revit versions, and optionally enable ZeConnect add-ons.

6. Inside Revit, users open the Ze'Manage tab and access modules based on their assigned role.

Installation/Uninstallation

Before installing Ze'Manage, ensure Autodesk Revit is fully closed, a valid Ze'Manage license key has been received from your Company Admin, internet connectivity is enabled for activation, and a supported Autodesk Revit version is installed on your system.

To install, double-click the Ze'Manage Setup installer, accept the Privacy Policy, enter the license key provided by your administrator, choose the Revit version(s) you want to install for, optionally enable the ZeConnect add-ons (NWC Export, Link Remapper), and click Install. Once installation is complete, open Revit and click "Always Load" on the security dialog so the Ze'Manage add-in loads automatically.

To uninstall this plug-in, exit Autodesk Revit if it is currently running, simply rerun the installer and select the "Uninstall" button. OR, click Control Panel > Programs > Programs and Features (Windows 7/8.1/10/11) and uninstall as you would any other application from your system.
