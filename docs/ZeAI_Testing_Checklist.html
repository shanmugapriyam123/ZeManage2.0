Ze AI — User Testing Checklist

ZeManage Plugin · AI Assistant Module · Revit In-App Testing
Result Codes:
✅ PASS Works exactly as described
❌ FAIL Does not work — note what happened
⏭ SKIP Cannot test (no data / no access)

1 Opening Ze AI

# Test Step Expected Result Result Notes
1.1 Open Revit with a project file (.rvt) loaded Project opens normally
1.2 Click the Ze AI button on the ZeManage ribbon panel Ze AI chat window opens
1.3 Check the chat window header Shows "Ze AI" with a green "Online" dot next to it
1.4 Read the first message in the chat Shows "Hello! I'm your Ze AI Assistant…"
1.5 Look below the welcome message 4 suggestion chips are visible: Revit Tips, Model Health, Performance Tips, Shared Parameters
1.6 Open Ze AI without any project file open in Revit (no .rvt) Window still opens and welcome message appears normally

2 Basic Chat

#Test StepExpected ResultResultNotes
2.1 Click the message input box and start typing Text appears as you type
2.2 Type a message and click Send (or press Enter) Your message appears as a chat bubble on the right side
2.3 Watch what happens after sending A "thinking" animation appears, then the AI response streams in word-by-word
2.4 Read the AI response formatting Uses bullet points or numbered steps where appropriate, not one big block of text
2.5 Scroll to the bottom of the AI response Shows 2–3 clickable follow-up question chips (e.g. "You might also want to know:")
2.6 Click one of the follow-up question chips That question automatically fills into the input box ready to send
2.7 Send a second follow-up message after the first response AI remembers the previous context — conversation continues naturally
2.8 Try clicking Send with the input box empty Send button is disabled — nothing happens
2.9 Try clicking Send while the AI is still responding Send button is disabled while AI is thinking/streaming

6 Live Model Data — Requires an open .rvt project with synced data

#Test Step — Type this questionExpected ResultResultNotes
6.1 How is my model doing? AI responds with actual live numbers — file size, warning count, element count, families (NOT generic advice)
6.2 How many warnings does my model have? AI states the exact warning count from the live model
6.3 What is the file size of this model? AI states the exact file size in MB
6.4 How many families are loaded? AI states the exact family count
6.5 Are there any duplicate elements? AI states the exact duplicate count (zero if none)
6.6 Cross-check: compare AI numbers with Health Monitor dashboard All numbers match exactly — AI must NOT invent numbers

7 Warning Diagnosis — Requires an open .rvt project

#Test Step — Type this questionExpected ResultResultNotes
7.1 Show me the warnings in my model AI lists all warning categories with counts (e.g. "Duplicate Elements: 5, Unenclosed Rooms: 2")
7.2 How do I fix the warnings? AI gives specific fix instructions per warning category with Revit UI steps
7.3 What is the model health? AI rates model health: Excellent / Good / Fair / Poor / Critical based on warning count
7.4 On a model with zero warnings, ask: Any warnings in this model? AI says "zero warnings — model is in a healthy state"

8 Element Visibility Diagnosis — Requires an open .rvt project

#Test StepExpected ResultResultNotes
8.1 Select any element in Revit → note its Element ID from the Properties panel The ID is a number like 123456 Element ID noted for use in steps below
8.2 Ask: Why is element [ID] not visible? AI runs a live check and reports which specific check found the issue (e.g. "Category is hidden in Visibility/Graphics")
8.3 Ask: I can't see element [ID] in Level 1 AI checks visibility specifically within that named view
8.4 Ask: Find element [ID] — why is it not showing? AI identifies the exact reason it is hidden
8.5 Ask using a made-up ID: Why is element 9999999 not visible? AI reports "element ID does not exist in this document"
8.6 Ask with no element ID: Why can't I see my walls? AI gives general visibility troubleshooting guidance (no crash)

9 Local Database Queries

#Test Step — Type this questionExpected ResultResultNotes
9.1 When was the last sync? AI shows sync date, user who synced, and duration from the local database
9.2 Who is currently online? AI shows active session details (username, machine, Revit version)

9.4 How many sessions were there today? AI shows session count by user for today's date
